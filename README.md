# Animalopoly
A command-line Monopoly-like game I made for Computer Science.

GUI requires Net.Processing, which can be downloaded [here](https://www.michelmichaud.com/netprocessing/NetProcessing.zip). Place NetProcessing.dll and NetProcessing.xml in the same folder as Animalopoly.csproj. 
Note that when running in debug mode, Net.Processing will create a warning popup in French. This can be ignored.
